What a view kind is made of

Adding a kind means writing one folder and one page file, then adding a line to each of four registries. Shared code reads only the registries, and checks fail when a piece is missing. test/diagrams.test.ts holds this page to the code: its file list, its registries and every path and name in it.

Written for the kindlib/views/<kind>/ + app/lab/kinds/<kind>.tsx

types.tsevery kind
the spec and result fields, added to ViewSpecs, ViewResultFields and ViewResultMain in lib/types.ts by declare module
run.tsevery kind
the runner: validates, refuses loudly, asks each site (askEachSite, answering in lib/views/shared.ts), combines, computes
kind.tsevery kind
the descriptor (ViewKindDef, lib/views/kind-def.ts): figure, title, results text, help, federation need, preview, isNew
doc.tsevery kind
its part of the DSL reference (KindDoc, lib/views/kind-doc.ts): Views row, agent grammar, gallery examples, one marked snapshot
sql.tswhen it has its own queries
aggregate-only builders returning AggregateSql; otherwise shared builders in lib/federation-views.ts or resolver methods
method.tsmost kinds
the method record and its Python script (lib/method.ts); a kind in lib/preview-kinds.ts may lack one
figure.tsmost kinds
result JSON to an SVG string, laid out with lib/chart/; table-only kinds have none
README.mda few
a kind with more to explain than docs/ARCHITECTURE.md's paragraph; read it before changing the kind
app/lab/kinds/<kind>.tsx every kind
its KindUi (app/lab/kinds/kind-ui.ts): add-view dialog entry and category, why it is disabled, the spec a new view starts from, the card's subtitle and Controls. The only JSX a kind writes.
Kinds never import each other: a kind's files import one another and the shared modules only. local/kind-boundary in eslint.config.mjs enforces it.

Shared code that reads themno kind is named here

The run
runAnalysis (lib/analysis.ts) builds each view's ViewRun (lib/views/run.ts) and calls its runner; the runner's queries go through viewAggregate (lib/federation.ts), which runs them per cohort and study and logs them
Figures and text
viewToSvg (lib/view-svg.ts) and lib/result-text.ts: the page's figure, MCP's image, the assistant's text
Rules and badges
lib/view-coverage.ts (which peers can answer), lib/preview-kinds.ts, lib/new-in-lab.ts, lib/view-help.ts
The DSL reference
lib/dsl-reference.ts → docs/dsl.md (npm run docs:gen), MCP describe_dsl, the Examples tab, the agent grammar
The page
app/lab/add-view-dialog.tsx, app/lab/view-cards.tsx and the shared card app/lab/kind-cards.tsx
Provenance
the method record, compiled SQL and notebook shown with each result

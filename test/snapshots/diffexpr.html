The 1,500 most significant genes are drawn as points and listed in the table, the rest drawn as density. Z-scores are standardised within each study, so a difference is in study-specific units. A test on thousands of samples finds tiny differences significant — read the effect, not only the q. Enrichment is preranked GSEA on the unrounded t (Subramanian et al. 2005, weight 1), significance from 1000 random sets of the same size drawn from the same ranking, seeded by the set's name so a shared link reproduces it; p = (b+1)/(m+1) over the same-sign nulls, q is Benjamini–Hochberg across the sets tested (not GSEA's own NES-based FDR). Gene-set permutation ignores gene–gene correlation, so it is anti-conservative next to phenotype permutation, which needs patient-level values.
